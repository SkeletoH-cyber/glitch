# Glitch — хоррор-мод (Fabric 1.21.1)

Бессмертная сущность Глич хочет сломать твой мир. Есть две концовки: ты изгоняешь его ритуалом
или мир рассыпается и больше не открывается.

## Сборка
Нужны Java 21 и Gradle 8.8+.
    gradle wrapper --gradle-version 8.8
    ./gradlew build
Готовый .jar окажется в build/libs/ (файл без -sources). Для запуска нужен Fabric Loader 0.16+ и Fabric API.
Версии зависимостей лежат в gradle.properties. Если Gradle ругнётся на версию Fabric API,
возьми актуальную для 1.21.1 на modrinth.com/mod/fabric-api.

ВАЖНО: проект написан без возможности скомпилировать его в среде, где он создавался (там не было доступа к Maven).
Возможны мелкие ошибки в именах методов Yarn. Если сборка выдаст ошибку, пришли текст, и я поправлю.

## Ход игры (дни Minecraft от создания мира)
| Время        | Стадия | Что происходит |
|--------------|--------|----------------|
| 0 – 0.5 дня  | 0 | Тишина, можно спокойно выживать |
| 0.5 – 2      | 1 | Шёпот и помехи на экране, пропадают факелы, появляются перевёрнутые кресты из незерака |
| 2 – 5        | 2 | Исчезают блоки вокруг игрока, вспышки тьмы |
| 5 – 8        | 3 | Появляется Глич: возникает перед игроком, скример, бьёт, перепрыгивает к цели |
| 8 – 12       | 4 | Стираются целые чанки поблизости, Глич приходит чаще |
| 12+          | 5 | Финал: мир стирается вокруг игрока, Глич появляется постоянно |

## Как остановить Глича
1. Находи кресты. Это 5 блоков незерака, перекладина внизу, в центре кристальный обсидиан, сверху красный факел.
   Глич создаёт их по одному примерно раз в 4000 тиков (до 8 штук). Их нельзя ломать, только использовать якорь.
2. Крафт Якоря реальности (4 штуки): 4 аметиста + 4 золота + 1 Око Эндера, форма «AGA / GEG / AGA».
3. ПКМ якорем по центру креста: якорь встаёт на место, крест исчезает. ПКМ в воздух покажет, в какой стороне ближайший крест.
4. После 4 якорей Глич сопротивляется 10 секунд и навсегда изгоняется. Мир остаётся как был.

Если не успеть до конца стадии 5, мир стирается, всех выкидывает с сообщением, и войти в него больше нельзя.
Если нужно вернуть такой мир: удали файл world/data/glitchmod_state.dat (мир будет пустым).

## Команды (нужен op)
    /glitch stage 0..5   прыгнуть на стадию
    /glitch spawn        призвать Глича перед собой (скример)
    /glitch cross        создать крест рядом
    /glitch status       стадия, якоря, кресты
    /glitch banish       изгнать немедленно
    /glitch reset        сбросить всё
Подсказка для тестов: /glitch stage 3, потом /glitch spawn.

## Что где настраивать
- GlitchState.STAGE_START — время начала каждой стадии (длина прохождения).
- GlitchState.ANCHORS_NEEDED, MAX_CROSSES — сколько якорей и крестов.
- GlitchDirector.secondly — частота событий, задержка между появлениями Глича.
- ChunkEraser.MAX_ACTIVE, LAYERS_PER_TICK — скорость стирания чанков (больше значения дают больше лагов).
- GlitchEntity.createGlitchAttributes — урон и скорость Глича.
- Звуки: используются ванильные (эндермен, Хранитель). Свои .ogg можно подключить через sounds.json.
- Текстуры в src/main/resources/assets/glitchmod/textures/ заменяются любыми PNG того же размера
  (скин Глича 64x64, лицо скримера 256x256).

## Структура
- GlitchMod: регистрация, команды, блокировка входа в разрушенный мир
- world/GlitchState: сохраняемое состояние (дни, стадия, кресты, якоря)
- world/GlitchDirector: все события и концовки
- world/ChunkEraser: постепенное стирание чанков
- entity/GlitchEntity: бессмертный Глич
- item/RealityAnchorItem: ритуальный предмет
- network/ScarePayload и client/*: скример, помехи, рендер Глича
